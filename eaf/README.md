## 🚀 Why EAF 2.0?

Traditional AI agents are limited by their models or environments. EAF 2.0 breaks these barriers with a unified orchestration layer that bridges the gap between local privacy and cloud power.

- **Universal Multi-LLM Core**: Integrated support for Gemini, Cloudflare, Z.ai, GLM, Groq, Anthropic, and **Ollama/GGUF**.
- **Egytronic_1.0 master model**: Native optimization for our signature model, achieving 99% accuracy in complex tool utilization.
- **Infinite Tool Registry**: Hyper-Scale tools for File Systems, Headless Browsers (Playwright), VM Execution, MCP, and Physical Device access.
- **Autonomous Lifecycle**: From scaffolding and development to benchmarking and global deployment on Cloudflare Edge.

## 🛠 Quick Start

### Installation
```bash
npm install -g @egytronic/eaf
```

### Initial Setup
```bash
eaf setup
```

### Launch Autonomous Builder
```typescript
import { UniversalAdapter, Agent, HyperDevTool } from '@egytronic/eaf';

// Initialize with Egytronic_1.0
const agent = new Agent(new UniversalAdapter('cloudflare', 'KEY'));
agent.addTool(new HyperDevTool());

await agent.run("Build a real-time agent orchestration platform and deploy to Cloudflare.");
```
